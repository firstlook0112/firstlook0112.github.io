全站以 Apple HIG 的层级、留白与系统字体为基础，叠加液态玻璃材质：透明层、边缘高光、环境色和指针镜面反射。原 liquid_glass_widgets 是 Flutter 组件库，本页是它的 Web 原生视觉适配。

07 / 使用规则

Do / Don't

玻璃是层级工具，不是装饰。大面积文字背后保持足够不透明度；每个区域只保留一个主行动。

Do

  • 页面底部使用浅灰环境光，玻璃才有可折射的层次。
  • 主按钮用 --primary-bg，文字链接用 --accent-strong。
  • 卡片圆角 22–26px，图片内缩 8px，保留边缘高光。
  • 移动菜单使用高不透明度玻璃，并在背后加模糊遮罩。
  • 新增颜色、圆角、阴影先进入 :root 令牌。

Don't

  • 不要在所有元素上叠加 backdrop-filter，性能会下降。
  • 不要用低对比的蓝色小字写正文。
  • 不要在玻璃卡片上再叠不透明大色块。
  • 不要用 --ink 反向做深色卡片，暗色模式会失效。
  • 不要重新引入旧模板 CSS 或 jQuery。

适配说明：liquid_glass_widgets 的 Flutter API 无法直接运行在静态 HTML 中；本实现保留其核心视觉特征（透明材质、边缘高光、环境折射、指针高光），不引入 Flutter Web 运行时，避免破坏 SEO 与加载性能。
